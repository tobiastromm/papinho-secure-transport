# Engineering history and release evidence

This directory contains historical engineering material and release evidence preserved for transparency, reproducibility, and auditability. It is not the canonical normative or user documentation; current documentation lives in the parent `docs/` directory and its language directories.

Historical records may describe intermediate states that were later superseded, and their presence does not imply that every proposal became final behavior. Release evidence is retained to support published project claims. This entire directory is intentionally excluded from source release packages.
