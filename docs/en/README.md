## Community

See [Contributing](contributing.md) and the [provider proposal guide](../provider-contributions.md). We welcome documentation, translations, reproducible builds, tests on real old machines, C89/VC6 work, adapters, providers, TLS research, and license/provenance review. Contributors need not be cryptographers.

English and pt-BR onboarding are maintained as semantic peers. A change to requirements, commands, security warnings, or limitations must update both; historical engineering evidence is linked rather than duplicated.
